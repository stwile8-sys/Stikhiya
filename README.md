# Стихия

Физическая песочница для Android в духе The Powder Toy, но с упором на реализм: настоящие единицы (°C, кг/м³, Дж), теплота плавления и кипения, растворы, впитывание, застывание клея, схватывание цемента, горение с доступом воздуха.

## Как получить APK

Каждый пуш в `main` собирает игру в GitHub Actions. Готовый файл — во вкладке **Releases**, ставится поверх старой версии.

## Что уже есть

- Мир 480 × 200 клеток, одна клетка — 1 см.
- 44 вещества с реальными свойствами: порошки, жидкости, газы, твёрдые, расплавы.
- Тепло: теплопроводность, конвекция воздуха и жидкостей, кипение у горячей стенки, теплота переходов.
- Смеси: соль и сахар растворяются (горячая вода растворяет больше сахара), песок впитывает воду и держит форму, клей ПВА впитывается в опилки и засыхает в «клеёные опилки», цемент и гипс схватываются с водой.
- Горение: нужен воздух, дерево без воздуха обугливается, спирт вспыхивает от искры, вода и углекислый газ тушат.
- Инструменты: кисть, ластик, нагрев, охлаждение, перемешивание, просмотр клетки.
- Пауза, шаг, замедление времени, ускорение медленной химии (×1 … ×3600).
- Режимы просмотра: обычный, температура, плотность, смеси.

## Устройство

- `core/src/main/kotlin/ru/stikhiya/sim` — движок физики на чистом Kotlin, без зависимостей.
- `core/src/main/kotlin/ru/stikhiya/game` — отрисовка и интерфейс на libGDX.
- `android` — запуск на Android.
